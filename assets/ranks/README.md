# Imágenes de rango de LoL

Descarga los emblemas oficiales y colócalos aquí con los siguientes nombres (en minúsculas):

| Archivo           | Rango         |
|-------------------|---------------|
| iron.webp         | Hierro        |
| bronze.webp       | Bronce        |
| silver.webp       | Plata         |
| gold.webp         | Oro           |
| platinum.webp     | Platino       |
| emerald.webp      | Esmeralda     |
| diamond.webp      | Diamante      |
| master.webp       | Maestro       |
| grandmaster.webp  | Gran Maestro  |
| challenger.webp   | Aspirante     |

## Fuentes para descargar los emblemas

Puedes descargar los emblemas oficiales desde:
- https://raw.communitydragon.org/latest/plugins/rcp-fe-lol-static-assets/global/default/ranked-emblem/
  (iron.png, bronze.png, silver.png, etc. — luego renombra/convierte a .webp)

Los archivos pueden ser .webp, .png o .jpg — el código intenta los tres en ese orden.
